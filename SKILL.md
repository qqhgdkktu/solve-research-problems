# Решение сложных задач

Сформулируй точный результат и критерий, по которому можно обнаружить ошибку. Начни с самой дешёвой проверки, различающей правдоподобные ответы: малый случай, предельный режим, контрпример, тест через обычный интерфейс или пересчёт с исходными знаменателями. Для заявления о новизне проверь предшествующие работы.

По умолчанию решай сам. Привлекай доступного субагента, если независимый метод, данные или проверка снимут конкретную неопределённость. Передай **один вопрос, нужные исходные данные, ожидаемый проверяемый результат и условие остановки**. Для независимого решения скрой ожидаемый ответ, для аудита покажи спорный переход. К [примерам поручений](references/assignments.md) обращайся, только если трудно сформулировать задание.

Из ответа сохрани вывод, свидетельство и существенное ограничение. При разногласии проверь наименьшее спорное утверждение. При провале продолжай, только если изменились метод, данные или проверка. Повторяющийся тупик сверни до одной строки, если она предотвращает повтор работы. Убирай остальное из контекста. Для долгого поиска задай предел ресурсов и сохраняй лишь подтверждённые промежуточные результаты с их зависимостями.

Проверь конечный артефакт: код из выдаваемого файла, исходную формулировку формальной теоремы или вывод на независимых данных. Верни решение и границы проверки. Если остался пробел, укажи точный недоказанный шаг или недостающее измерение.
